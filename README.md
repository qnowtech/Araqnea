# Araqnea

Araqnea makes quantum circuits approachable by translating OpenQASM 2.0 into interactive ZX-calculus diagrams.

## Features

- Live OpenQASM validation with Bell, GHZ, and Hadamard test presets
- ZX diagram translation for H, X, Z, S, T, Rx, Rz, CNOT, and CZ gates
- Interactive spider inspection and a built-in probability preview
- Browser-ready Qollab `main.js` export using Qiskit JS conventions

## Development

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for static checks.
